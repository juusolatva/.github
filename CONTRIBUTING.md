# Contributing

Thanks for your interest in contributing! This is a personal project maintained on a best-effort basis, so responses may take some time.

## Reporting Bugs

Open an issue and include:

- What you expected to happen and what actually happened
- Steps to reproduce
- Version or commit, operating system, and any relevant configuration

For security vulnerabilities, do **not** open a public issue. Follow the [security policy](SECURITY.md) instead.

## Suggesting Changes

For anything beyond a small fix, please open an issue first to discuss the idea. This avoids spending time on changes that may not fit the project.

## Pull Requests

1. Fork the repository and create a branch from the default branch.
2. Keep changes focused. One pull request should address one thing.
3. Follow the existing code style and the project's formatter or linter, if one is used.
4. Add or update tests and documentation where relevant.
5. Make sure the project builds and all tests pass.
6. Describe what the change does and why, and link any related issue.
